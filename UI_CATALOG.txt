STATUS TRANSITIONS (Server-Validated)
================================================================================

SUBMITTED -> IN_REVIEW (Verify action)
IN_REVIEW -> APPROVED (Approve action, app master auto-created for NEW_APPLICATION)
IN_REVIEW -> REJECTED (Reject with reason)
APPROVED -> ONGOING (Assign Team action)
ONGOING -> ON_HOLD (Hold with reason, SLA paused)
ON_HOLD -> ONGOING (Resume action, pause accumulated)
ONGOING -> DONE (Complete action, SLA calculated, FINAL)
REJECTED -> SUBMITTED (User resubmit only)

REQUEST TYPES (2)
================================================================================

NEW_APPLICATION
- Version: Auto 1.0.0 (read-only)
- On Approval: request_applications entry auto-created
- Fields: Title, Description, Urgency, Phone, Business Need, Objective, Expected Output, File

RFC (Request for Change)
- Version: User specifies, must be > current_version

- Fields: Application, Requested Version, Description, Urgency, Phone, Business Need, Objective, Expected Output, File
